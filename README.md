# 中文词向量实验室

用 Python + Streamlit 演示腾讯中文词向量：相近词探索、两词相似度、找不同、词语的加减法，以及135个地名的二维/三维可视化。

本仓库提供应用源码，不包含两个大型词向量模型文件。下载源码后，需要另行准备模型；教师提供的完整版ZIP则已包含模型。

## 学员：使用完整版ZIP

1. 安装 **64位 Python 3.12**，安装时勾选“Add python.exe to PATH”。当前实测版本为3.12.14。
2. 获取教师提供的 **`vector-demo-full-v1.0.0.zip`**。如果本仓库已发布Release，也可从 **Releases → Assets** 下载完整版附件。
3. 将ZIP完整解压到普通文件夹，不要在压缩包里直接运行。
4. 打开解压后的 `vector-demo` 文件夹，双击 **`start_demo.bat`**。
5. 首次运行会自动安装Python依赖，需要联网并等待安装完成。浏览器通常会自动打开；也可打开窗口提示的地址，一般是 `http://127.0.0.1:8517`。
6. 演示运行期间保持命令窗口打开。关闭窗口会停止服务。

后续启动仍双击同一个文件。模型已包含在完整版ZIP里，依赖安装完成后，查询与可视化均在本机执行。

> 绿色 `Code → Download ZIP` 和自动生成的 `Source code (zip)` 只包含源码，不包含约864 MB的模型文件。需要解压后直接启动的学员，请使用教师提供的完整版ZIP。

## 使用说明

- 相近词探索支持自由输入词语，点击后显示候选词、向量图和完整100维数值。
- 找不同有四道固定题，每题独立显示答案。
- 加减法有两道固定题，点击后计算最接近的词。
- 词向量空间先列出135个地名，点击二维或三维按钮后计算；两种结果互相保留，悬停显示地名与坐标。
- 三维图支持旋转、缩放；二维图支持平移、缩放。
- t-SNE先对100维向量进行L2归一化，使输入距离与余弦相似度对应；参数在原134个地名上比较选取，并在当前135个地名上重新验证邻居保留率和trustworthiness，固定随机种子。坐标完全由算法生成，没有按地名或行政区划调整位置。
- 二维坐标轴采用相同比例，三维采用数据比例。投影仍有信息损失，图中距离不能直接当作原始语义距离或地理距离。

## 只有源码时

从 `Code → Download ZIP` 下载源码并解压后，自行把配套模型放进 `data` 目录，或设置 `WORD_VECTOR_MODEL_PATH` 指向 `.bin` 文件。在包含 `app.py` 的文件夹中双击 `start_demo.bat`，也可运行：

```powershell
python -X utf8 bootstrap.py
```

默认只监听本机地址。需要多人共用服务器时，应另行配置服务器部署。

## 教师发布与模型来源

发布步骤见 `PUBLISHING.md`，模型来源与第三方许可说明见 `THIRD_PARTY_NOTICES.md`。模型文件不提交到普通Git仓库，由教师通过完整版ZIP另行分发；发布Release时，可将完整版ZIP作为附件上传。

二维与三维图使用相同的8组颜色：对原始100维词向量归一化后进行KMeans聚类（固定随机种子），再将分组映射到两种降维图。颜色表示辅助向量分组，并不表示行政区划，也不能保证所有相近词都属于同一组。悬停可查看地名、分组及坐标。

本次二维、三维投影的参数、评价方法与对照结果见 `projection-validation.txt`，逐地名结果及全部候选配置见 `projection-validation.json`。

当前地名共135个：已新增南京市，原“未知位置”替换为澳门，两种可视化同步更新。
